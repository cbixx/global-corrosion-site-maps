颜色相容性修复计算器

本工具基于目标混凝土的 L*、a*、b* 颜色值，计算 MPC 修复砂浆的推荐颜料组合与掺量。

模型适用范围： 本工具基于固定的 28 d MPC 砂浆基准色及经验线性调色模型。 计算结果仅用于初步配方参考，实际工程或试验使用前应进行实验验证。

输入数据

请输入目标混凝土表面的 L*、a*、b* 值。

MPC 基准色： L* 43.55 / a* 2.23 / b* 9.62 约束： 0 ≤ D < 12%; n ≤ 3 色差： ΔE*ab(76)

计算结果

推荐方案按最小色差排序。

等待输入
请输入目标混凝土 L*、a*、b* 后点击“计算推荐方案”。
