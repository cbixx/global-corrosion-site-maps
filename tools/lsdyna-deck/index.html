LS-DYNA Model Explorer & Deck Editor

Study how an LS-DYNA model is assembled, trace relationships between parts, sections, materials, elements and analysis settings, reconstruct modelling decisions step by step, compare keyword decks, and make controlled edits without leaving the browser.

Local processing: Keyword decks are read and processed only in this browser. They are not uploaded to Corrosion Atlas or sent to an external server.
01

Explore

Understand the reference model before changing it. Inspect its parts, elements, sections, materials, contacts, constraints, initial motion, controls, and requested outputs.

Goal: understand what exists in the model and how the components are linked.

02

Reconstruct

Follow the original modelling logic from geometry and element formulation through materials, contacts, boundary conditions, loading, analysis controls, and database output requests.

Goal: reproduce the model deliberately rather than copying keyword cards.

03

Compare

Compare a reconstructed deck with the reference model, or compare modelling cases such as normal and oblique impacts, while focusing on engineering differences rather than raw line-by-line text.

Goal: identify exactly which modelling decisions have changed.

Local model workspace

Open a reference LS-DYNA keyword deck

Start with the model you want to understand or reproduce. Choose one .k, .key, .dyn, .inc, or other text-based keyword file.

No file upload

The original file remains unchanged. The model is parsed locally so that its structure and recognised analysis settings can be studied before any edits are made.

Interpretation boundary: This tool is intended to support model study, reconstruction, comparison, and controlled editing. It is not a replacement for the LS-DYNA keyword reader, LS-PrePost, or the solver. Constructs such as *INCLUDE, *PARAMETER, curves, transformations, advanced contact options, and unsupported card formats may be preserved without being fully interpreted.

Reconstruction workspace

Built for understanding a model, not only editing it

Subsequent workspace functions will connect each physical model component to its LS-DYNA part, section, material, elements, interactions, constraints, and analysis controls. An interactive model preview will allow those relationships to be inspected directly in the browser.
