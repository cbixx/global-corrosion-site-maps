LS-DYNA Deck Navigator & Editor

Inspect a single LS-DYNA keyword deck, review recognised model inputs, make limited parameter edits, run basic consistency checks, and export an edited copy for verification in LS-PrePost and LS-DYNA.

Local processing: Your keyword deck is read and processed only in this browser. It is not uploaded to Corrosion Atlas or sent to an external server.

Inspect

Review recognised parts, materials, sections, nodes, elements, initial motion, boundary conditions, contact cards, controls, and output requests.

Edit

Adjust selected common parameters through a guided interface, or edit individual keyword blocks directly through the raw editor.

Verify

Run lightweight deck checks before exporting a copy. Final validation must still be carried out with the LS-DYNA keyword reader and solver.

Local browser tool

Open an LS-DYNA keyword deck

Choose one .k, .key, .dyn, .inc, or text-based keyword file.

No file upload

The original file remains unchanged. Any edits are kept in browser memory until you explicitly export a new _edited.k file.

Important limitation: This is a browser-side aid, not a full LS-DYNA keyword reader. Constructs such as *INCLUDE, *PARAMETER, curves, transformations, advanced contact options, and unsupported card formats may be retained but not fully interpreted by the guided editor.
